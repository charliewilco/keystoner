# Seed provenance

The initial catalog was researched from public government/provider sources on 2026-11-09. It contains 108 benefit pathways, 117 source records, and 52 category labels. The SQL is the editable source of truth; published SQLite snapshots derive from it.

Each pathway retains original paraphrased summaries, eligibility/access instructions, cost classification and qualifications, funding basis, availability, source citations, review dates and evidence status. Some research relied on official search-result excerpts. Review dates reflect online research, not provider confirmation. Program rules and availability can change. No resident profile is stored. Legacy priority values are research ordering, not recommendations or personalized rankings.

The original research schema is retained with a `resources` view and release metadata added by the publisher. Research-context wording in metadata was generalized for public distribution. No provider content is represented as owned by Keystoner. Source titles and URLs identify third-party sources whose content remains subject to their terms and rights.
